# Moji Chat

A modern real-time chat application built with React, Node.js, Socket.IO and MongoDB.

## ✨ Features

### 🔐 Authentication

- Email & Password Authentication
- Google OAuth Login
- JWT Access Token
- Refresh Token Authentication
- Protected Routes
  
### 👥 Friend System

- Search users
- Send friend requests
- Accept / Reject friend requests
- Friend list management

### 💬 Messaging

- One-to-one chat
- Group chat
- Real-time messaging with Socket.IO
- Message seen status
- Unread message counter
- Online user indicator
- Automatic conversation update
- Latest message preview

### 👨‍👩‍👧 Group Chat

- Create group chat
- Add multiple members
- Group conversation list

### ⚡ Real-time

- Receive messages instantly
- Update conversation without refreshing
- Read receipt synchronization
- Online users synchronization
